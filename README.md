# Reviewer — HTML/CSS/JavaScript edition

Front-end recreation inspired by the original PHP theme.

## Included
- Responsive header and mobile navigation
- Website URL validation
- SEO report interface with expandable checks
- Score cards and progress indicator
- Local report history using localStorage
- Dark mode
- Print / Save as PDF

## Important limitation
The original application uses PHP and MySQL. A static HTML/CSS/JavaScript version cannot execute server-side PHP, access the original database, perform server-side crawling, authentication, or administrator operations. Report values in this version are a local demonstration. Connect the interface to a secure backend/API to make analysis real.

## Run
Open index.html or deploy the repository on GitHub Pages, Cloudflare Pages, Netlify, or another static host.
