Privacy Policy

Reviewer SEO Tools respects user privacy and is designed to collect as little information as practical.

Website analysis

When you request an analysis, the URL you submit is sent to the Reviewer server endpoint so it can request PageSpeed Insights results. The PageSpeed API key is kept on the server and is not exposed in the page source.

Cookies and browser storage

The application uses browser local storage to remember your cookie-consent choice. The theme preference may also be stored if that feature is extended. These settings are functional and do not identify you by themselves.

Optional services

At present, the application does not require an account. If analytics, advertising or other third-party services are added in the future, this policy should be updated before they are enabled.

External services

Website analysis relies on Google PageSpeed Insights. Third-party services may process requests according to their own policies and terms.

Contact

For privacy questions, use the contact page.
