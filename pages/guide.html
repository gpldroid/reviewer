Reviewer SEO Tools Guide

1. Analyze a website

Enter a complete website address, such as https://example.com, and select Analyze. Reviewer sends the address directly to Google PageSpeed Insights and displays Lighthouse categories and important audits.

2. Understand the main SEO checks

Pay attention to the page title, meta description, crawlability, canonical URL, headings, descriptive link text and image alternative text. These signals help search engines and users understand a page.

3. Improve performance

Review Core Web Vitals and loading metrics such as Largest Contentful Paint, Cumulative Layout Shift and Total Blocking Time. Optimize images, reduce unnecessary JavaScript, improve caching and remove resources that delay rendering.

4. Mobile and accessibility

Use the mobile result as an important baseline. Make sure pages have a viewport declaration, a language attribute, usable contrast, meaningful image alt text and accessible interactive elements.

5. Technical SEO basics

Use HTTPS, a canonical URL where appropriate, a valid robots.txt file and an XML sitemap. Keep important pages internally linked and make sure search engines can access the content you want indexed.

6. Comparison

The comparison feature runs the same mobile PageSpeed analysis for two URLs so you can inspect their Performance and SEO scores side by side. Scores are measurements from the analysis at the time it runs, not permanent rankings.
